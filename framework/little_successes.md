# Little successes

The questions in the framework are designed to lead the student through helpful mental operations on their way to a problem's solution. The fact that a mental operation is helpful means that there is value and achievement in practicing it, irrespective of whether the entire problem is solved; this is a "little success".

Several of the [questions used in the planning phase](questions_for_planning.md) point the student towards simpler versions or variations of the problem at hand and suggest solving those first, or making a connection between the simpler problem's solution and a possible solution to the current problem.

Rather than looking down on these little successes, the framework encourages the student to seek them out.

See [signs_of_progress.md](signs_of_progress.md) for the observable signals that count as little successes within a dialogue.
